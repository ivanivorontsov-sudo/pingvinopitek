Пингвинопитек

Linux (Debian 13, XFCE) внутри Windows — с ИИ-помощником ИванОператор.

Сначала нужен образ Linux (≈2 ГБ, один раз).

Репозиторий приватный: для загрузки из программы впишите токен GitHub в ⚙ Настройках, либо скачайте части pingvinopitek-debian13.qcow2.partNN из релиза в браузере и укажите первую часть.

Программы Linux

Запустите Linux.

ИИ-оператор

ИванОператор работает внутри Linux и сам управляет его рабочим столом: нажимает, печатает, открывает программы.

Задача попадёт в буфер обмена Linux и ИванОператор откроется — вставьте её (Ctrl+V) в поле задачи.
